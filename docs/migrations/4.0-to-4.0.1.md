# cached 4.0.0 -> 4.0.1 Migration (Agent Instructions)

Versions: `cached 4.0.0` -> `cached 4.0.1`

`cached_proc_macro` and `cached_proc_macro_types` did not change; leave them pinned at
`3.0.1` and `3.0.0` respectively if pinned directly.

## Breaking changes

None. This release changes a dev-dependency only (`smartstring` replaced by `compact_str` in the
macro tests). Nothing under `src/` changed, and the dev-dependency is not in a consumer's
dependency graph.

## New APIs

None.

## Detection

Nothing to detect. No existing call site changes meaning.

## Required Cargo.toml change

```toml
# Before
cached = "4.0.0"

# After
cached = "4.0.1"
```

```
cargo build

```
