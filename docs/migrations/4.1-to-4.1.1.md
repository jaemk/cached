# cached 4.1.0 -> 4.1.1 Migration (Agent Instructions)

Versions: `cached 4.1.0` -> `cached 4.1.1`

`cached_proc_macro` and `cached_proc_macro_types` did not change; leave them pinned at
`3.0.1` and `3.0.0` respectively if pinned directly.

## Breaking changes

None. This release only changes documentation: the store re-exports at the crate root are
marked `#[doc(inline)]`, so rustdoc generates `cached/struct.<Name>.html` pages for them. No
public API or runtime behavior changed.

## New APIs

None.

## Detection

Nothing to detect. No existing call site changes meaning.

## Required Cargo.toml change

```toml
# Before
cached = "4.1.0"

# After
cached = "4.1.1"
```

## VERIFY

```
cargo build
cargo test
```

No new compile errors are expected from the version bump.
